# Public SIFAP legacy landing

This directory is the maintainable source for the public, trilingual
introduction at <https://workshop-gbb.github.io/datacorp-sifap-legacy/>.
It is deliberately separate from the authenticated runtime assets under
`infra/adabas-natural-lab/`.

The static page shares the SIFAP editorial identity and uses a restrained
phosphor-green terminal aesthetic. Its access actions open the visible Azure
viewer entry in the same tab:

<https://sifap-lab-438k30.eastus2.cloudapp.azure.com/login?locale=pt-BR>

The Azure origin creates the opaque, read-only viewer session through an
explicit same-origin form. GitHub Pages does not collect credentials, create
sessions or embed the terminal. Administration remains restricted to operators,
and the public workshop viewer uses only synthetic data.

Do not link an unauthenticated visitor directly to `/terminal/`. The raw ttyd
route needs a valid viewer session. The old Basic Auth gateway returned an empty
HTTP 401 in embedded browsers, which looked like a blank page.

## Local preview

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory public-landing
```

The site and demo share one Portuguese/English/Spanish dictionary. The language
selector uses `?lang=pt-BR`, `?lang=en` or `?lang=es`, propagates the selection to
the demo, home and Azure links, and updates an open demo without losing its query,
filters, pagination or guide step. No cookies or local storage are required.

The page uses local ES modules and has no CDN, analytics or frontend package dependencies.
Inter and JetBrains Mono use the unmodified Fontsource 5.3.0 files and included
SIL Open Font License notices.

## Public artifact

Export exactly the approved presentation files to a new or empty directory
outside this private checkout:

```bash
python3 scripts/build-public-landing.py /tmp/sifap-public-landing
```

The exporter copies the allowlisted landing, shared language modules, demo
HTML/CSS/modules and synthetic snapshot, favicon, fonts and license notices,
then adds `.nojekyll` (15 files in total). It rejects missing assets, symlinks, nonempty destinations
and destinations inside this checkout. Do not copy repository history, runtime
status, infrastructure, the Natural corpus or application payloads to Pages.

GitHub Pages publishes the root of the dedicated `gh-pages` artifact branch.
Repository visibility remains private while Pages access is public and HTTPS is
enforced. The source follows the normal reviewed `impl/` to `develop` workflow;
publishing the presentation does not merge `main` or deploy Azure.

## Complete offline simulation

The simulation is a **dedicated full-screen page** at [`demo/`](demo/), opened in a
new tab from the landing. It has no site header or footer: the browser window is
the terminal. It replaces the instructor `demo-html/sifap-terminal.html` script
while keeping its menu, command line, history, program lists, report, blocked
operations, help, logout and guided walkthrough. The supplied instructor files
remain unchanged; the maintained, published version lives here.

The screen is a real character grid: exactly **80 columns by 24 rows**, uppercase
ASCII, `HORA`/`DATA` header with program name, level, user and library, `===`
separators, a `===>` command line, PF keys and a status line. Text is measured at
runtime, so the grid fills the whole window at any size and refits on resize.
Phosphor green, scanlines, vignette and a restrained flicker complete the CRT;
the flicker stops under reduced-motion. Because browsers only allow full screen
after a gesture, the page enters full screen on your first click or keystroke,
and the **Tela cheia** button toggles it at any time.

The demo explicitly identifies itself as a browser simulation. It does not run
Natural, call Azure, open a WebSocket, collect credentials or write to a database.
**Every link opens in a new tab**, including the separate live-system entry.

Current technical references are Natural CE 9.3.3, Adabas CE 7.4.0, DBID 12,
SIFAPPRD, VIEWBENF/CONSBENF and Adabas files 150-153. No COM-PLETE, DBID 047 or
invented legacy program names are claimed to be running.

The snapshot contains 500 synthetic beneficiaries, six programs, 2,000 payments
and 200 audit events generated by the laboratory's deterministic seed functions.
It is a **historical 2017-2018 teaching fixture**, not current production benefit
rates or a live database snapshot. Only needed display fields are exported; bank
accounts, contact details, identity hashes, operator sessions and IP addresses
are excluded. Amounts use integer cents and appear without a currency symbol, as
terminals printed them, with the currency named in the column header. Reports
total the selected fixture period; they do not execute BATCHREL or implement
production benefit calculation. Known fixture imbalances are preserved, not
silently repaired.

Regenerate the snapshot without modifying the laboratory's seed or database:

```bash
python3 scripts/export-demo-fixtures.py
```

### Navigation

Start the demo, then use the visible menu, query forms and pagination controls.
The guided tour has ten explicit steps and can be stopped or restarted; there
are no background typing loops. Functions and error messages are translated.
Record names, Brazilian locations, identifiers and protocol codes stay unchanged.

| Command | Simulation action |
|---|---|
| `START` | Start or re-enter the local viewer demonstration |
| `1` / `2` | Beneficiary query / payment history |
| `3` / `LIST` | Select a program / list all beneficiaries |
| `4` / `5` | Payments for a selected fixture period / consolidated report |
| `6` / `7` | Show blocked maintenance / batch operation |
| `8` / `9` | View synthetic audit events / log out |
| `BENEF CPF=00097539740` | Query the lab's first synthetic beneficiary |
| `BENEF NIS=81977930374` | Query the same synthetic beneficiary by NIS |
| `PAG NIS=81977930374` | Show its payment history |
| `HELP` / `PF1` | Help and command list |
| `GUIDE` / `PF2` | Start the guided tour |
| `BACK` / `PF3` | Previous screen |
| `MENU` / `PF12` | Main menu |
| `LOGOFF` | End this simulated session |

Browser F5/F12 shortcuts are not intercepted; use the visible PF buttons or type
their commands instead. These demo commands are **not** a permission to run
commands in the real Natural viewer, which remains pinned to VIEWBENF.

## Verification

Run the public-source contracts with the existing lab test environment:

```bash
python3 -m pytest \
  infra/adabas-natural-lab/tests/test_landing_contract.py \
  infra/adabas-natural-lab/tests/test_public_landing_export.py \
  infra/adabas-natural-lab/tests/test_demo_snapshot.py -q
```

The existing pytest gate also runs the dependency-free Node state-machine and
translation tests. Browser validation must exercise all three languages,
query/error/blocked states, history, filters, pagination, exact report totals,
the guided tour, reset/logout, keyboard and mobile layouts. No request may leave
the Pages origin during simulated interactions.

Offline simulation checks do not prove the Natural terminal is operational. For
a **live viewer** release, use an anonymous real browser to verify separately:

1. The Pages access action stays in the same tab and opens the Azure entry.
2. The visitor explicitly starts the viewer session without a password.
3. `/viewer` embeds a visible xterm and receives real Natural output over its
   WebSocket.
4. Viewer access receives HTTP 403 for `/admin/`.
5. Logout removes the viewer session.

Do not accept a mocked navigation, an HTTP 200 by itself or a bare 401 challenge
as end-to-end terminal evidence.
